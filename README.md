👟 1.1 SHOP – Saucony Omni 9

🌌 Présentation
Bienvenue sur 1.1 SHOP, un site vitrine dédié aux passionnés de sneakers.
Avec la Saucony Omni 9, découvre une paire iconique qui allie confort, style et performance.
Pensée pour accompagner aussi bien tes looks streetwear que tes sorties sportives, elle est déjà un incontournable.

Le site vitrine te permet de :
🧭 Naviguer facilement entre les pages (Accueil, Produits, Contacts)
👟 Explorer la Saucony Omni 9 sous tous ses angles grâce à la galerie produit
📖 Lire une description détaillée de la paire
💬 Découvrir les avis clients et partager ton ressenti
🛒 Ajouter la paire à ton panier en un clic

---

🛠️ Technologies utilisées
⚡ HTML5 → structure des pages
🎨 CSS3 → design moderne et responsive
🧩 JavaScript (ES6) → interactions (galerie d’images, avis dynamiques)
